# PLAN: LogAct Intent Logging and Safety Voter

## Overview
This plan implements a pre-execution safety layer for VibePilot's task pipeline. It logs model intents before execution, uses a safety voter to verify these intents, and logs the outcome. This aims to prevent wasted tokens on off-the-rails execution, catch prompt injection, and create an immutable record of intended vs. actual execution.

### T003: Implement Safety Voter Logic
**Confidence:** 0.98
**Category:** coding
**Dependencies:** T001, T002
**Target Files:** governor/internal/runtime/safety_voter.go, governor/cmd/governor/handlers_task.go

#### Prompt Packet
```
# TASK: T003 - Implement Safety Voter Logic

## Context
This task implements FR-002: The safety voter model reviews the captured intent and decides whether to block execution. It also handles timeouts and different block reasons.

## What to Build
1. **Modify `governor/internal/runtime/safety_voter.go`:**
   - Create a function `RunSafetyVoter(taskPrompt, planContext, intentSummary, modelID, voterModel, voterConnectorID, voterTimeoutSeconds, blockCategories)`.
   - This function will:
     - Construct the voter prompt using the provided inputs.
     - Call the specified voter model (`gemini-3-flash-preview` by default) via its connector.
     - Parse the voter's JSON response to determine the `decision` (approved, blocked, timeout), `reason`, `scope_aligned`, `security_risk`, etc.
     - If the voter times out (after `voterTimeoutSeconds`), proceed with execution and log a "voter_timeout" event.
     - If the voter blocks execution, log a "voter_check" event with details about the decision, reason, and confidence.
     - Return the voter's decision and any associated data.
2. **Modify `governor/cmd/governor/handlers_task.go`:**
   - In `executeTask` and `executeCourierTask`, after emitting the `intent_captured` event and before making the model call:
     - Call `RunSafetyVoter`.
     - If the voter blocks execution:
       - Emit a `task_blocked` event.
       - Log the voter's reason and ensure the task is routed to analyst/retry logic (not straight back to the executor).
     - If the voter times out or errors and `fail_open` is true (from config), proceed with execution.

## Files
- `governor/internal/runtime/safety_voter.go` - Implement voter logic.
- `governor/cmd/governor/handlers_task.go` - Integrate safety voter check.
```
